# Acute #3 experimental plan: improvements developed and implemented 2026-09-18

Purpose: use the surgery-suite day to its maximum. Every change below is tied to a
measured shortfall of acutes #1/#2 and to a tool that now exists in the repo. Timed
runbook: `RIG_DAY_ACUTE3_TEMPLATE.md`. Surgery-day timing: `docs/SURGERY_DAY_ACCELERATION_2026-09-18.md`.

## B. Changes implemented (tools) and the experiment they enable

1. **Placement gates** (`rig/placement_gate.py`, validated both directions on both acutes).
   Cortical: 40-thwack block → GO/MARGINAL/NO-GO + grid focus + shift hint. Thalamic: 4-min
   quick probe → responsive pairs, knees, footprint rank + ladder hint. Replaces listening
   and the 30-min probe-then-fit loop for POSITIONING. Saves ~1.5-2.5 h per day.
2. **Burst / duty-cycled designs** (`rig/design_burst_probe.py`: burst-ladder, duty-prbs,
   gap-scan, with validator + meta). Enables: (a) recruitment vs burst length (1/3/10
   pulses), (b) the recovery-gap scan that sets the operating duty, (c) ONE 5-min
   multi-pair ID run at a non-saturating duty in place of three tonic ladders, (d) a
   burst carrier during the arms. This is the lever for recovering rank 2-4 for real MIMO.
3. **y-liveness alarm** (`rig/check_y_liveness.py`): first-minute check on every capture,
   `--watch` mode; validated on the 09-10 live and dead captures. Ends the PZ2-off class of
   loss (~1.3M µA-ticks and 3 runs on 09-10).
4. **Timed 2-person runbook** (`RIG_DAY_ACUTE3_TEMPLATE.md`): engineer work moved off the
   critical path; first arm targeted 16:00; cut list ordered by information value.
5. **Stimulus-pattern analysis** (`stim_patterns.py`, both days): the per-site command
   comparison now regenerates with `run_all.py`; charge is reported above hold.
6. **Array-status analysis** (`rank_array_status.py`): pulse footprints, rank, knees,
   ladder geometry — the standing answer to "is it the electrode?" (it is not).

## C. The acute-#3 science, in priority order

1. **Burst-vs-tonic rank recovery (primary).** Burst-ladder probe (13 min) → per-pair
   footprints at 1/3/10-pulse bursts; gap scan (2 min) → recovery gap; duty-PRBS ID (5 min)
   on the responsive pairs → MIMO fit + `check_mimo_rank` gate. Prediction from the pulse
   data: eff. rank ≥ 2 at duty ≤ 0.3 with ≥ 200 ms gaps (Chung 2002 / Swadlow & Gusev 2001
   / Hughes 2022 depression-recovery regime; LIT_B themes).
2. **Decoupled-target MIMO run** (first-in-class exhibit) — only meaningful if (1) passes.
3. **Burst-vs-tonic paired arms** on the same schedule: does a duty-cycled carrier keep the
   plant's rank while the MPC tracks? Report r, above-hold charge, and the drift re-probe.
4. **Time-controlled R sweep**: R ∈ {100, 30, 10} interleaved in 20-event blocks within one
   12-min run (drift cannot confound the charge-fidelity frontier); analysis = per-block r
   and above-hold charge with block order as a covariate.
5. **Early/late repeat** of run r1 (both arms): cheapest drift number; never cut.
6. **NN arm re-formulated** (forward model on burst-ID data + optimisation, or MPC behaviour
   cloning) per `docs/NN_METHODOLOGY_REVIEW_2026-09-18.md`; deploy only if held-out R² on
   the control channel clears the linear baseline by a stated margin.

## D. Reporting conventions adopted (so the weekly and results decks stay comparable)

* Charge: report total AND above-hold; hold is a design parameter (the knee), not a result.
* Rank: quote SVD effective rank at 0.1·σ1 with the σ spectrum, separately for pulse
  footprints (raw LFP), tonic gains (feature space), and the fitted plant (`check_mimo_rank`).
* Placement: gate verdict + z table in the ledger row; never the audio impression.
* Every arm run: y-liveness line, delivery audit line, tracking JSON, gate PNG in the ledger.
