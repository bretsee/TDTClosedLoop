## Red flags (say them immediately)
- The liveness window BEEPS / says `DEAD` (or `run_audit` says `y=DEAD`) → amplifier/PZ2 off. Stop the run.
- `AUDIT …: FAIL` → the next `2_loop` refuses to start until you type `override`; the surgeon decides.
- **Any crash or abort of a stim run → `.\rig\stim_zero.ps1` first**, then diagnose.
- B never prints `policy=fresh` by tick ~100 → Ctrl+C in B, restart B, `go` again.
- `Skipping … to position` in B → Synapse recording was started too early; stop, restart B, start recording LAST.
- `pull_blocks -Once` prints no `NEW BLOCK` after a round-trip → the block never reached the SSD
  (recording still open, or robocopy run before Synapse closed it); the gates would read a STALE block.
- Never re-run Synapse Detect mid-day (08-29); never start another program on this PC during a run.
